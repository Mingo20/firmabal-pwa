# FirmAbal · captura territorial de afiliaciones (PWA)

Plataforma móvil para gestionar, recolectar y auditar afiliaciones políticas en el terreno (República Dominicana).

- Flujo de captura de 4 pasos: Configurar (WhatsApp), Cédula (OCR con puter.js), Revisar datos, Firma manuscrita
- Consentimiento de protección de datos (bottom sheet)
- Centro de control con métricas, meta y registros por día
- Registros con buscador, filtro de estado y ficha detallada
- Firmas con detalle y descarga de PDF individual
- Mapa Leaflet/OpenStreetMap, auto registro por enlace, exportación PDF/CSV
- Instalable como PWA, datos locales en el dispositivo (localStorage)

Prototipo de demostración: los datos viven en el navegador. Para producción se requiere backend con autenticación, cifrado y auditoría conforme a la ley 172-13.
